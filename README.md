# Ramzur — лендинг

Одностраничный сайт-визитка компании Ramzur (AI-агенты, автоматизация процессов, разработка ПО). Собран как статические файлы — HTML/CSS/JS без сборки и без бэкенда.

## Файлы

```
index.html                      — разметка и содержимое всех разделов
style.css                       — все стили
script.js                       — вся логика: меню, анимации, модальное окно, формы
build-single-file.mjs           — сборка одностраничной копии (см. ниже)
ramzur-landing-single-file.html — та же страница одним файлом (генерируется)
```

Все три основных файла должны лежать в одной папке — `index.html` подключает
`style.css` и `script.js` относительными путями.

`style.css` разбит на разделы (токены → база → примитивы → компоненты →
анимация → reduced-motion), `script.js` — на нумерованные блоки, оглавление
есть в начале каждого файла.

### Одностраничная копия

`ramzur-landing-single-file.html` — та же страница, собранная в один файл
(удобно переслать или открыть без сопутствующих файлов). Файл **генерируется**,
править его вручную не нужно: после любых изменений в трёх основных файлах
достаточно выполнить

```
node build-single-file.mjs
```

## Как посмотреть локально

Просто открыть `index.html` в браузере — сервер не нужен. Для GitHub Pages: включить Pages в настройках репозитория, указать ветку и корень `/` — сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

## Что нужно сделать перед публикацией

В коде помечено классом `ph` (пунктирная рамка, видна прямо на странице) всё, что требует реальных данных от Ramzur:

1. **Блок «в цифрах»** в шапке — число проектов, лет на рынке, отраслей, довольных клиентов.
2. **Раздел «О компании» → карточка «Команда»** — 1–2 факта, вызывающих доверие.
3. **Услуга «AI-агенты»** — количество дней бесплатной поддержки.
4. **Услуга «Автоматизация»** и **«Разработка ПО»** — выбрать один из предложенных вариантов бонуса «сверху».
5. **Гарантия сроков** — согласовать точную юридическую формулировку условий компенсации.
6. **Контакты** — телефон, Telegram/WhatsApp, e-mail.

Полный список также продублирован в комментарии `CHECKLIST-BEFORE-LAUNCH` в конце `index.html`.

## Форма заявки (важно)

Обе формы — основная в разделе «Контакты» и модальное окно, которое открывается по кнопкам-CTA — сейчас **не отправляют данные никуда**: они только показывают сообщение об успехе локально в браузере. Перед запуском нужно подключить реальную отправку. Точки интеграции размечены комментарием `TODO-BACKEND` в `script.js`. Варианты:

- Telegram Bot API (webhook на бота компании);
- e-mail-сервис через простой backend-эндпоинт;
- CRM-вебхук (amoCRM, Bitrix24 и т.п.).

## Модальные окна

Кнопки с классом `js-open-modal` (почти все CTA на странице) открывают одно общее модальное окно вместо перехода к разделу «Контакты». Заголовок, подзаголовок и подсказка в поле «задача» берутся из атрибутов `data-title`, `data-sub`, `data-placeholder` на самой кнопке — так что при необходимости добавить ещё один CTA с таким же поведением, достаточно скопировать один из существующих `<button class="js-open-modal" ...>` и поменять текст/атрибуты.

## Раздел «Портфолио / Кейсы»

Сознательно не включён (по договорённости на этапе текста). В `index.html` оставлен комментарий с указанием, куда его добавить, когда появятся кейсы — между блоками `#about` и `#services`, с той же сеткой карточек, что используется в `#services`.

## Адаптивность

Брейкпоинты (используются согласованно во всех разделах):

| Ширина | Что происходит |
|---|---|
| 1024px | двухколоночный hero и панели складываются в одну колонку |
| 940px  | меню в шапке уходит под бургер (пять русских пунктов перестают влезать) |
| 880px  | остальные двухколоночные сетки складываются |
| 620px  | hero-график скрывается: на телефоне он стоит больше прокрутки, чем даёт |
| 460px  | блок «в цифрах» становится одной колонкой |

Вёрстка проверена на реальных ширинах от 320px до 1600px — горизонтальной
прокрутки нет ни на одной.

## Доступность

Ориентир — **WCAG 2.1 AA**.

- **Контраст.** Все 58 текстовых узлов страницы проходят AA; минимальное
  измеренное значение — 4.72:1. Шкала текста: `--text` (17.3:1),
  `--text-muted` (8.1:1), `--text-faint` (5.6:1 на фоне страницы, 4.7:1 на
  светлых поверхностях). Понижать `--text-faint` нельзя — это и есть нижняя
  граница AA.
- **Клавиатура.** Единый видимый фокус (`:focus-visible`) на всех элементах,
  ссылка «Перейти к содержимому», в модальном окне — ловушка фокуса
  (Tab по кругу), Escape на закрытие и возврат фокуса на кнопку, которая его
  открыла. Закрытое модальное окно получает атрибут `hidden`, поэтому его поля
  не попадают в порядок обхода Tab.
- **Скринридеры.** Ориентиры `header / nav / main / footer`, `aria-expanded` и
  `aria-controls` на бургере, `aria-current` на активном пункте меню,
  сообщения об успехе — в `role="status"` с `aria-live`, ошибки полей связаны
  с инпутами через `aria-describedby`.
- **Движение.** При системной настройке «уменьшить движение»
  (`prefers-reduced-motion`) все анимации — вступление hero, скролл-reveal,
  бегущий сигнал по линии, пульсация, hover-сдвиги и плавная прокрутка —
  отключаются, содержимое сразу показывается в конечном состоянии.
- **Без JS страница остаётся читаемой.** Скролл-reveal скрывает блоки только
  при наличии класса `js` на `<html>`, поэтому с отключённым JS (и в поисковых
  краулерах) страница отрисовывается полностью. Дополнительно есть страховка:
  через 2.5с всё, что осталось скрытым, показывается принудительно.
- Размер тач-целей — не меньше 44×44px.

## Анимация

Вся анимация построена на экспоненциальных ease-out кривых (токены
`--ease-out-quart / quint / expo`) — движение замедляется к концу и никогда не
«отскакивает». Ключевые моменты:

- **Вступление hero** — один срежиссированный выход блоков по порядку чтения;
  сделан на CSS-анимациях, а не на классах, поэтому не зависит от JS.
- **Hero-график** — разрозненные узлы «ручной рутины» проявляются с задержкой,
  затем прочерчивается единая линия, и по готовому маршруту время от времени
  проходит короткий яркий сигнал. Этот же мотив «одной непрерывной линии»
  повторяют полоса прогресса прокрутки и подчёркивание активного пункта меню.
- **Скролл-reveal** подобран под то, что показывает: панель «как мы работаем»
  выезжает со своей стороны, пункты чек-листа — по направлению чтения,
  карточки поднимаются, шаги процесса отрабатывают по очереди как
  последовательность.
- **Счётчик в блоке «в цифрах»** включается сам, как только вместо `XX`
  появится настоящее число (класс `ph` при этом нужно убрать).
- Анимируются только `transform`, `opacity` и фильтры — свойства, не
  вызывающие пересчёт вёрстки. Полоса прогресса использует `scaleX`, а не
  `width`.

## Производительность

- Из Google Fonts запрашиваются только те насыщенности, которые реально
  используются (Unbounded 600/700, Golos Text 400/600/700, JetBrains Mono
  400/600). При необходимости офлайн-версии шрифты нужно захостить
  самостоятельно.
- Обработчик прокрутки обновляется не чаще одного раза за кадр.
- Hover-эффекты объявлены внутри `@media (hover: hover)`, чтобы не «залипали»
  на тач-устройствах.
