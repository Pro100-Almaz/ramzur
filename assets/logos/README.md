# assets/logos

Логотипы клиентов для раздела «Клиенты» на главной странице.

Требования к файлу:

- **Формат:** SVG с прозрачным фоном (предпочтительно). PNG допустим, но нужен
  вариант @2x под retina-экраны.
- **Фон:** обязательно прозрачный. Логотип на странице приводится к одному
  белому цвету, и непрозрачная подложка превратится в белый прямоугольник.
- **Обрезка:** без лишних полей вокруг знака — отступы задаёт вёрстка.
- **Имена файлов:** `client-1.svg` … `client-6.svg` (или осмысленные имена, тогда
  поправьте `src` в разметке).

Как подключить — в `README.md` в корне проекта, раздел «Раздел «Клиенты»»,
и в комментарии над блоком `CLIENTS / SOCIAL PROOF` в `index.html`.

**Перед публикацией:** нужно письменное согласие клиента на использование его
логотипа.
